# Mouse gestures in the inventory

First release of Mouse, now with its own repository. It brings to 1.8.9 the two Mouse Tweaks gestures that actually get used, written from scratch.

- **Shift and drag**: hold Shift with the left button and sweep the cursor across slots — every slot it crosses sends its whole stack to the other inventory, with no click-by-click.
- **Scroll over a slot**: the wheel over a slot moves items between the top and the bottom inventory. Clicks go out one per tick, so the server accepts all of them.
- **Where to turn it on and off**: each gesture has its option on the Mouse page of the Panel (Insert).
- **Needs Stein Loader 0.1.9**: every mod now asks for the Loader released today, so there is no version mix nobody tested. With an older one, the mod shows up in the list with the reason written out.
